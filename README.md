# Hệ Thống Gợi Ý Địa Điểm Ăn Uống Theo Vị Trí & Chat AI

## Cấu trúc thư mục
- `/backend`: Mã nguồn xử lý API, kết nối CSDL, tích hợp NLP/LLM và thuật toán xếp hạng.
- `/frontend`: Giao diện người dùng (Chat AI, Bản đồ GPS, Bộ lọc đa điều kiện, Trang Admin).
- `/database`: Chứa file schema SQL (15 bảng) và dữ liệu mẫu.
- `/docs`: Tài liệu SRS, Thiết kế CSDL & Module, Sơ đồ Draw.io và Product Backlog.
